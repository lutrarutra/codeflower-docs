Every sandbox runs all of them. Each chat is one agent's: choose it when the chat starts (the agent switch above
*New chat* in the app's window, the pick in VS Code). `codeflower run`, `task` and `tui` take the agent with
`--agent ID` (or `CODEFLOWER_AGENT`). How to sign each in: [Signing in agents](/guides/sign-in/).

<AgentsTable />

Model, effort and other settings are each agent's own: the chat shows what it offers, and
[`codeflower task`](/guides/sandbox-run-task/#task) takes them by name.
